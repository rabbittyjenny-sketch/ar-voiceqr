เพียงแค่เปิดกล้องมือถือ สแกน QR Code แล้วดู AR Hologram ได้ทันที ผ่านเว็บเบราว์เซอร์

📱 + 📷 + 🔲 = ✨
1 เปิดกล้องมือถือ
เปิดแอป Camera บนมือถือ iPhone หรือ Android
📱 iPhone: แอป Camera ปกติ
🤖 Android: Google Camera, Samsung Camera, หรือแอปกล้องปกติ
2 ส่องไปที่ QR Code
ชี้กล้องไปที่ QR Code ของ ราศีตุลย์
🎯 ระยะห่างประมาณ 15-30 ซม.
📏 ให้ QR Code อยู่ในกรอบกล้องให้ชัดเจน
3 ระบบ Detect QR Code
เมื่อกล้องเห็น QR Code จะขึ้น ลิงก์ (URL) ที่ด้านบนหน้าจอ
🔍 iPhone: แจ้งเตือนที่ด้านบน
🔍 Android: ป๊อปอัพหรือแจ้งเตือน
4 กดเข้าไปที่ลิงก์
แตะที่ ลิงก์ที่ขึ้นมา เว็บเบราว์เซอร์จะเปิดขึ้นมาเอง
🌐 Browser: Chrome, Safari, Edge หรือเบราว์เซอร์ปกติ
⚡ Auto-Open: ไม่ต้องคัดลอกลิงก์
5 ดู AR Hologram!
เว็บจะแสดง AR ของ ราศีตุลย์ ได้ทันที:
🎬 Video Hologram: วีดีโอลอยลื่นพร้อมเอฟเฟค
💎 หินประจำราศี: รูปภาพหินลอยด้านล่าง
📝 ข้อความ: คำทำนายและรายละเอียดราศี

🔲 QR Code ตัวอย่าง

QR Code ที่สร้างไว้จะลิงก์ไปที่:

index.html?sign=libra

(QR Code จริงควรสร้างจาก URL เต็มของเว็บไซต์ที่ deploy แล้ว)

⚙️ เทคโนโลยีที่ใช้ (WebAR)

  • HTML5 + CSS3: โครงสร้างและเอฟเฟค AR
  • JavaScript + Fetch API: ดึงข้อมูลจาก Google Sheets
  • WebAR Techniques: จำลอง AR ผ่านเว็บเบราว์เซอร์
  • Responsive Design: ใช้งานได้ทุกขนาดหน้าจอ
  • Cross-Platform: iOS, Android, Desktop

⚠️ ข้อควรระวัง

  • ต้องมีการเชื่อมต่ออินเทอร์เน็ตเพื่อดึงข้อมูลจาก Google Sheets
  • QR Code ต้องลิงก์ไปยัง URL ที่ถูกต้องและเข้าถึงได้
  • เว็บไซต์ต้องdeploy บน server (ไม่ใช่ไฟล์ local)
  • วีดีโอและรูปภาพต้องเป็น URL ที่เข้าถึงได้สาธารณะ
